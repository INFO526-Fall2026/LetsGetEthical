# LetsGetEthical
Used for an in-class activity to explore principles around ethics in data visualization. 

Below are the in-class goals for this activity. 

Goal #1: Familiarize yourselves with the folder format and topic. Review the output from the code in the folder. We will call this the "Before" plot. 

Goal #2: Identify ethical issues with the plot. Think about what we read for today, things like: Mechanics (Schermann) Are axes truncated? Is color mapping linear and perceptual? Responsibility (Cairo) Is source data clearly cited? Is privacy protected? Is it colorblind friendly? Power & Dignity (Correll): Does this reduce humans to anonymized dots? Goal #3: Create an "After" plot. Using what you have, recreate the plot based on what you discussed. 

Goal #4: Once you have created an "After" plot, each group will share out the findings, highlighting the "Before" and "After. When we share our findings, each student will speak from their role’s perspective. Each group will have about 5 minutes total share. 
1. Data Lead (R Coder): Explains technical mechanics—what chart types, scales, axes, color palettes, or data transformations were changed in R and why.
2. Ethics Lead: Connects the redesign to the readings (citing Schermann, or Correll)—explaining how the "Before" chart weaponized abstraction, power, or visual deception, and how the "After" chart restores integrity.
3. Client / Executive: Speaks to the organizational trade-offs—how the new design still achieves the core objective (persuasion, clarity, actionability) without compromising ethics.
4. Affected Community Representative: Speaks on the human impact—how subjects in the data are represented, whether privacy/dignity is protected, and whether the chart avoids harmful stigma or misinterpretation.
